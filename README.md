# Bookings & Reservation System

This is a simple web application that allows users to book and manage reservations for a hotel or other accommodation. 

It is built using:
- Go 1.23.5
- [Chi](https://github.com/go-chi/chi) router & middleware
- [alex Edwards SCS](https://github.com/alexedwards/scs) session manager
- [NoSurf](https://github.com/justinas/nosurf) CSRF protection
